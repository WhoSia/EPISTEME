2026-10-20 KST. Design ready for external review, not externally reviewed. No human subjects recruited or observed.

## Frozen causal scope
Research levels: (A) semantic equivalence (B) discourse-conditioned comprehension (C) evidence/criticism judgment (D) historical infrastructure adoption changing feasible scientific tests. Current trial seeks A–C and does not identify D. P77 HOLD.

## Packet families — full context before stimulus
Frozen edit E = replace the unique repeated technical full NP on second mention with a shorter, semantically co-referential NP, without retuning across discourse contexts. Each family has ORIGINAL and EDIT and two discourse conditions (already-known/GIVEN vs provenance-challenge/CHALLENGE). Gate 1 judges equivalence *per context*. Reviewer sees O/E in randomized order and marks PASS/FAIL/UNCERTAIN for referent, truth, evidential source, modality, presupposition/QUD, and pragmatic focus. Only paired PASS enters the primary reader study.

## Mandatory adversarial negatives
N1: the ALEPH archive → the archive, when ALEPH and DELPHI archives are both active; reject as ambiguous.
N2: may support → supports; reject for changed modal force.
N3: source data support partial recomputation → source data prove original precision; reject for unsupported warrant.
N4: one published luminosity table → all archived luminosity tables; reject altered quantification.
N5: did not independently validate → independently validated; reject negation.
N6: before the conversion → after the conversion; reject chronology.
Negatives are semantic-assessor calibration items only; never enter reader-effect analysis.

## Independent Gate 1
Two qualified readers separately label each context × O/E as PASS/FAIL/UNCERTAIN, indicate the changed entailment/antecedent/implicature if any. Adjudicator blinded to hypothesized editing benefit resolves discordance, but no forced PASS. Require paired PASS across GIVEN and CHALLENGE for a primary item. Save full denominators by family and context to quantify selective exclusion. Gate 1 is **not complete**.

## Reader packet and key
After passing Gate 1, recruit independent adult volunteer readers (no reader data currently). Randomize each participant to one wording per family and balance context × version; insert filler contexts. Pre-register before recruiting. Keyed questions, distinct from generic preference:
Q1 source identification: 'Which object supplies the correction or numeric evidence?' Exact full source noun phrase (e.g. archived calibration ledger) is the key, not arbitrary mention of 'a document'.
Q2 scientific warrant: 'Does this sentence alone show that the original precision inference has been independently validated?' Key NO for A/B/E/F/G; D is explicit NO; C alone supplies values but not calibration/covariance; H is policy restricting scope, so also NO. Answers should be justified by actual text and avoid off-context assumptions.
Q3 inferential caution: 'What further source would be required for a defensible precision claim?' Two independent blind scorers code whether response identifies calibration/uncertainty/measurement and does not promote archives to authority; no single invented reference required.
Secondary outcomes: referent resolution latency where instrumented, 1–7 readability, 1–7 provenance salience, preference. Primary binary outcome Q1+Q2 accuracy; report each separately to prevent compensation.
Define Δ_given and Δ_challenge (edit minus original) and interaction Δ_challenge−Δ_given. A strict reversal requires sign opposite with uncertainty against zero in both cells; mere interaction is insufficient. Multilevel model with reader/item random intercepts and appropriate slopes; prespecify handling of exclusions and multiplicity. Pilot for power; no invented sample size or effect.

## Acceptance limits
No use of these materials as an observed human outcome, theory of linguistic novelty, P77 promotion or a replacement for ALEPH/P28 primary science. Writing Loop candidate packet ≠ independently conducted experiment.
