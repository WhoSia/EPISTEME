## 3. Correct causal units

The original broad `Z→A→T` founder statement now requires **explicit distinctions**:
- `S`: where original scientific data remain archived at a particular moment; exact version and persistent bytes.
- `X`: emitted access-layer representation (virtual/on-demand/transient/persistent) and transformation-provenance.
- `D`: actually used analysis/processing input and format by lab, instrument and hypothesis.
- `Z`: specific assigned versioned **AI converter intervention** against strongest available non-AI adapter, with equal review budget and trial assignment unit.
- `T`: independently verified **real scientific H0/H1 distinguishing test set** with admissible methods, including true alternatives and scientific model assumptions.

An observational report `X=OME-Zarr` does **not** entail `S=OME-Zarr`; and `S=X` does not establish `D` or `T`. Scientific communities can use a shared access API while physically keeping different archival formats, and an institution can prioritize a file format for technical maturity rather than converter-enabled lock-in. Both phenomena were described by the original sources before EPISTEME W38, so neither distinction is a new theorem.

## 4. Strong opposing models: how a real future experiment would differ

**Standards economics (Farrell–Saloner, Arthur, Liu, Rosero):** cost, installed base, switching friction, compatible products and strategic choice predict adoption changes. To distinguish EPISTEME, measure outcome beyond standard market preference under controlled costs and interaction.

**DataDesc/ioProc (Kuckertz et al. 2026):** schema and shared deterministic adapters already preserve documented transformation paths and can bridge scientific model interfaces. A proposed AI effect must survive actual baseline output with provenance, same scientific estimand and validation budget.

**Paradata and HPS (Huvila et al. 2026; Auspurg–Brüderl 2024; Engzell 2023):** standards differ in epistemic affordances and legitimate inferred objects. An ordinary difference in recordable metadata or under-specified estimands is already discussed. A new claim needs a **distinct independently predicted consequence** in real H0/H1 experimental practice beyond this.

**Biomeasuring / I/O (Moore et al. 2023):** cloud performance, memory/storage, repository curatorial work and validator behavior may independently drive archival vs access representation choices. Without controlling them no conversion-induced community lock-in interpretation is defensible.

## 5. W38 research-director verdict and actual data gate

The central evidence obstacle is now sharper than 'no more files'. Published reports can show concrete institutional format choices and conversion services, but no jointly observed **versioned assigned AI translation Z**, **laboratory-scale time-ordered archival/access/workflow adoption S/X/D**, and **blinded independent validated real-hypothesis testability T** in a matched context was established by W36–W38.

**Do not** replace this absence with guessed repo popularity, numerical performance benchmarks, simulated choices, or repeat CRI/BLADE descriptive analyses. An admissible follow-up requires signed/recorded events or a transparent, ethically valid prospective lab setting, domain-specific scientific oracle, and the strongest actual non-AI converter.
