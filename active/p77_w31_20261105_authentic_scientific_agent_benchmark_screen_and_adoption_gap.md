## 2. New actually checked scientific agent benchmark candidates

The following are **live source-code README checks**, not successfully installed or executed by EPISTEME. They support feasibility screening only.

**Candidate BLADE:** [behavioral-data/BLADE](https://github.com/behavioral-data/BLADE), [paper](https://arxiv.org/abs/2408.09667). Original GitHub README was actually fetched and read, describing real research question/dataset pairs, expert-annotated grounded analytical decisions, construct selection, transformation and modeling decisions, grading. Contains tasks grounded in many-analyst studies and subject-matter expert decisions. README advertises Apache-2.0 software and ODC Attribution for data (verify actual file-level conditions before reuse). *Reason to consider*: more directly tied to **defensibility of an analytical pathway** than headline numerical p-value matching, and supplies a strong existing evaluation benchmark rather than pretending to invent one. *Fatal limitation*: no observed randomized AI *format-converter* intervention by itself, and no community-wide scientific **standard adoption** time series.

**Candidate BixBench:** [Future-House/BixBench](https://github.com/Future-House/BixBench), [dataset listing](https://huggingface.co/datasets/futurehouse/BixBench), [paper](https://arxiv.org/abs/2503.00096). Original live GitHub README fetched and read. Describes **205 questions from 60 real published computational-biology Jupyter notebooks/capsules**, open-ended/multiple-choice agent tasks, programmatic evaluation and code-execution access; its setup instructions mention Hugging Face authentication for dataset access. *Reason to consider*: authentic scientific data analysis with runnable artifacts and reference evaluation as potential H0/H1 **subtask** comparator. *Fatal limitation*: a correct task score is not itself an accepted epistemic test of a substantive biology hypothesis, and no collective standard lock-in intervention is identified.

Additional web search on AI scientist evaluation surfaced multiple broader scientific agent benchmarks (some released in 2026). These were **not** independently verified in original repo/data/experimental unit and are **NOT** promoted to positive evidence on this search snippet alone.

## 3. Three distinct research questions and admissible data

1. **Engineering subtask:** Can a specified versioned AI interface preserve predefined, expert-defensible analytic transformations across two concrete representation schemes? Candidate BLADE/BixBench may offer target source artifacts/oracles. Strong baseline is original code, best existing official/deterministic converter, and independent expert judgment under equal budgets. Benchmarks already evaluate agents; the novelty of a new metric requires much stronger demonstration.
2. **Epistemic condition:** Does the translation preserve the meaning, sampling assumptions, instrument link, uncertainty and provenance needed to distinguish substantive H0/H1? This must be judged by a source-authentic scientific oracle, not 'run completed' or coincident p-value. Existing metascience, workflow provenance and measurement literature directly compete.
3. **Collective coordination:** Does AI translation causally change community incumbent/challenger standard adoption (network interaction) and the scientifically testable options after allowing credible alternatives? Neither candidate benchmark README describes source evidence for this. **No joint dataset or genuine field treatment identified.**

The model `Z→A→T` is not identified from `Z→technical task score`; a good agent benchmark alone cannot rescue the founding TLP. Strong economic rivals Farrell–Saloner, Arthur, Liu, Heinrich and Rosero remain.
