## Primary source court — Moore 2021
- Original pp.1496–1498 deliberately present **OME-NGFF as a complement, not replacement** for OME-TIFF/HDF5. Their preferred representation depends on cloud/object storage, repeated random access, multi-resolution image needs, local tools, and transfer costs.
- Their Figure 1 is a reproducible **synthetic data/chunk retrieval performance** benchmark, sampling 100 chunks in 2D CycIF and 3D light-sheet conditions, comparing local/HTTP/S3 and TIFF/HDF5/Zarr. Source asserts cloud direct-access OME-NGFF performance at least an order of magnitude faster than monolithic HDF5 for tested conditions; this is NOT an estimate of experimental adoption or of scientific-H0/H1 discrimination. Their 3D TIFF condition failed memory capacity. A different serving layer (HSDS for HDF5 or OMERO for TIFF) may change comparison but imposes infrastructure.
- Documented **countervailing cost**: smaller chunks create more files and slower bulk copy; local HDF5 and NGFF were similar in their stated use case. Figure 1 is not a global proof of Zarr supremacy, and generated synthetic images are not a biological truth oracle.
- Explicitly **non-AI** `bioformats2raw` conversion and `raw2ometiff` appear in their synthetic generation route. Authors already propose tool/version evolution and interoperability across scientific standard families. This is stronger prior art than an EPISTEME claim that mere converter choice, storage representation, or improved remote throughput constitutes new epistemic path dependence.

## Primary source court — Gonçalves & Musen 2019
- Source pp.1–3 reports **11,409,262** metadata records from separate **2017** repository snapshots: NCBI BioSample 6,615,347 (obtained 2017-06-25, no source version manifest) and EBI BioSamples 4,793,915 (2017-11-15, obtained via IT helpdesk). The sum was independently checked arithmetically: 6,615,347 + 4,793,915 = 11,409,262. It is a sum of metadata records across repositories, NOT proven disjoint biological specimens.
- Their actual target is compliance of metadata attributes with expectations (ontology term, controlled field/value, required type and parseability), versus lower-fidelity string clustering; some arbitrary free-text cases are difficult to validate computationally.
- The source already anticipates crucial concepts in Long 2026 and Sundaram 2026: metadata inconsistency, fields that look equivalent yet differ in constraints, missing/invalid values, nonstandard field names, and obstacles to discovery/reuse. [Original authors' code](https://github.com/metadatacenter/metadata-analysis-tools), [original released 2017 data and validation outputs](https://doi.org/10.6084/m9.figshare.6890603). **No model-assisted harmonization treatment or downstream observed standard-adoption panel** in this historical dataset.
- **Temporal transport negative control:** 2017 NCBI/EBI metadata and 2026 BioSample/GEO query evaluations differ in source database, snapshot date, sample grain, task, metric and curation process. Treating these as untreated AI-vs-AI cohorts would violate design comparability.

## Fatal-rival and independent research judgment
Moore 2021 identifies (representation → access latency/cost) with a strong deterministic-conversion and storage baseline. Gonçalves 2019 identifies (metadata quality → search/reuse difficulty) descriptively with explicit validation algorithms. The current founding causal chain (Z_{AI} → A_{community standard} → T_{valid scientific criticism}) needs the SAME research unit and time-indexed use/decision observations, cost-matched non-AI rivals, original source path, explicit scientific H0/H1 and an independent warrant oracle. Neither paper contains those outcomes; associating their numbers is invalid.

A useful bounded **independent scientific contrast** is now: for ONE versioned input and one predeclared scientific operation, measure original access vs deterministic OME-NGFF conversion vs a separately justified AI alternative, with identical search, compute resources and valid reference answers. Even this alone measures a technical workflow, NOT collective standard switching or available scientific criticism. W53/W54 already show source/derived pixel equivalence for selected frames and temporal sensitivity of downstream analysis; do not relabel that as AI-induced test loss or restart the S-BIAD602 main line absent the director's reopening evidence.
